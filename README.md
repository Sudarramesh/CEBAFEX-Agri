# CEBAFEX Agri — Streamlit

Streamlit deployment repository for CEBAFEX Agri.

**Mobile setup:** Upload the `CEBAFEX_Agri_Streamlit_Cloud_Ready.zip` archive to this repository using GitHub's **Add file → Upload files**. The GitHub Actions workflow extracts the app into the repository automatically. Once it finishes, deploy with [Streamlit Community Cloud](https://share.streamlit.io) using `app.py` on the `main` branch.

**Important:** This version is a demonstration. There is no login protection and its local SQLite file may be lost on a Streamlit Cloud restart. Do not use real farmer or buyer information.
